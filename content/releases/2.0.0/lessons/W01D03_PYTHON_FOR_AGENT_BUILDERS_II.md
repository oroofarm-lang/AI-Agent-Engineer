### דוגמה מקומית

דוגמה זו מדגימה את המנגנון בלי לקרוא למודל. העתק אותה לקובץ `lab.py`, הרץ `python3 lab.py`, ואחר כך בצע את מעבדת הכשל. פלט קבוע של הדגמה אינו תשובת AI.

```python
"""Validated conversation persistence. Corrupt input is never silently erased."""
import json
import os
from pathlib import Path
from tempfile import NamedTemporaryFile


def validate(messages: object) -> list:
    if not isinstance(messages, list):
        raise ValueError('conversation must be a list')
    for message in messages:
        if not isinstance(message, dict):
            raise ValueError('message must be an object')
        if message.get('role') not in ('user', 'assistant'):
            raise ValueError('unsupported role')
        if not isinstance(message.get('content'), str):
            raise ValueError('content must be a string')
    return messages


def load_messages(path: Path) -> list:
    try:
        content = path.read_text(encoding='utf-8')
    except FileNotFoundError:
        return []
    return validate(json.loads(content))


def save_messages(path: Path, messages: list) -> None:
    validate(messages)
    path.parent.mkdir(parents=True, exist_ok=True)
    temporary = None
    try:
        with NamedTemporaryFile(mode='w', encoding='utf-8', dir=path.parent,
                                delete=False) as handle:
            temporary = Path(handle.name)
            json.dump(messages, handle, ensure_ascii=False, indent=2)
        os.replace(temporary, path)
    finally:
        if temporary is not None:
            temporary.unlink(missing_ok=True)


if __name__ == '__main__':
    from tempfile import TemporaryDirectory
    with TemporaryDirectory() as directory:
        path = Path(directory) / 'conversation.json'
        save_messages(path, [{'role': 'user', 'content': 'שלום'}])
        print(load_messages(path))
```

### שלבי המימוש

שמור שתי הודעות ופתח את קובץ ה־JSON בעורך. זהה רשימה, מילון ושדות. סגור את התוכנית, פתח מחדש וטען את אותן הודעות: התהליך הסתיים והנתונים שהיו בזיכרון אבדו, אך הקובץ נשאר.

## Concepts

JSON מייצג נתונים ואינו שומר אובייקטי Python שרירותיים. יש להבחין בין כשל פענוח, קובץ חסר ותוכן שמבנהו שגוי. טיפול בחריגה צריך לשמר את הראיה ואת הקובץ המקורי.

יישם את ההסבר על התוצר שלך: סמן מה נקבע מראש בקוד, מה נקרא ממקור ומה נוצר או הוערך על ידי מודל. אלה מסלולים שונים של אחריות. ערך שנוצר אינו נעשה עובדה רק מפני שהוא כתוב בשדה מובנה.

### קבצים, JSON וחריגות

`import json` טוען מודול מהספרייה הסטנדרטית. `json.loads` ממיר טקסט JSON לערכי Python; `json.dump` כותב ערכים לקובץ. JSON תומך באובייקטים, מערכים, מחרוזות, מספרים, ערכים בוליאניים ו־null. פונקציה או מחלקה אינן הופכות מעצמן לרשומה תקינה.

`try` ו־`except` מאפשרים לטפל בכשל מסוים. קובץ שלא קיים הוא מצב שונה מקובץ שאי אפשר לקרוא בגלל הרשאה. JSON תקין תחבירית יכול להיות בעל מבנה שגוי: `{}` מתפענח היטב, אבל אינו רשימת הודעות. לכן פענוח ואימות חוזה הם שני שלבים.

`with` סוגר את הקובץ גם אם מתרחשת חריגה. `Path` מייצג נתיב; `encoding='utf-8'` מגדיר קידוד מפורש. הדוגמה כותבת לקובץ זמני באותה תיקייה ומחליפה את יעד השמירה אחרי כתיבה תקינה. היא אינה מסד נתונים עם תמיכה בעדכונים מקבילים. אל תציג אותה כפתרון לשני תהליכים שכותבים אותה שיחה בו־זמנית.
