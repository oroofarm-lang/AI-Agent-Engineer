## Build First

בנה פונקציה route(command, text) התומכת ב־research, summarize ו־extract. החזר מילון עם action ו־result. התחל בפעולות מקומיות המסומנות כהדגמה, ללא קריאת מודל.

1. פתח תיקיית עבודה נפרדת. כתוב ב־README מהו הקלט, מהו הפלט ומי רשאי להפעיל את התהליך.
2. צור דוגמה קטנה בתחום שבחרת: עסק שמקבל פנייה מלקוח. השתמש בשם בדוי ובנתוני בדיקה; אל תחבר לקוח אמיתי בשלב הבנייה.
3. הגדר את התוצאה המצופה לפני ההרצה: רשומה, מסמך, שינוי מצב או פעולה. הפרד בין תוצאה שמודל הציע לבין פעולה שהקוד ביצע.
4. ממש מסלול תקין אחד. אם זו משימת אפיון, מסור תרשים וטבלת החלטות במקום קוד מיותר. אם נדרש ספק חיצוני, בדוק גישה והרשאות בתיעוד המקושר ושמור את גרסת החבילה.
5. שמור קלט, פלט ומזהה הרצה. השווה את התוצאה לציפייה והראה היכן היא תואמת והיכן לא.


### דוגמה מקומית

דוגמה זו מדגימה את המנגנון בלי לקרוא למודל. העתק אותה לקובץ `lab.py`, הרץ `python3 lab.py`, ואחר כך בצע את מעבדת הכשל. פלט קבוע של הדגמה אינו תשובת AI.

```python
"""Deterministic command router. These placeholders do not call an AI model."""

def route(command: str, text: str) -> dict:
    if not isinstance(command, str) or not isinstance(text, str):
        raise TypeError('command and text must be strings')
    command, text = command.strip().lower(), text.strip()
    if not text:
        raise ValueError('text must not be empty')
    handlers = {
        'research': lambda value: {'query': value, 'status': 'not_searched'},
        'summarize': lambda value: {'preview': value[:40], 'status': 'not_summarized'},
        'extract': lambda value: {'words': value.split(), 'status': 'local_split'},
    }
    if command not in handlers:
        raise ValueError('unknown command')
    return {'action': command, 'result': handlers[command](text)}


if __name__ == '__main__':
    print(route('extract', 'hello agent builders'))
```

**מבחן קבלה:** קורא אחר יכול לשחזר את הבנייה מהתיעוד ולבדוק את התוצר, בלי לדעת מראש איזו תוצאה רצית לקבל. עלויות וחיבורים לשירותים אינם מופעלים דרך אתר הלמידה.

### שלבי המימוש

הרץ תחילה `route('extract', 'שלום עולם')`: התוצאה צריכה להכיל שתי מילים. שנה את הקלט לרווחים ובדוק שהפונקציה דוחה אותו. כעת כתוב פונקציה `count_words(text)` שמחזירה מספר, והוסף אותה למילון הנתב. השאר את המבנה החיצוני `action` ו־`result` זהה.

בנה רשימה של שלוש פניות ועבור עליה ב־`for`. שמור את התוצאות ברשימה חדשה. השווה בין הדפסה בכל איטרציה לבין החזרת כל התוצאות: מי יכול להשתמש בכל אחת מהאפשרויות בהמשך?

## Concepts

מחרוזת היא טקסט, רשימה שומרת סדר ומילון מקשר מפתח לערך. פונקציה מקבלת קלט ומחזירה תוצאה; תנאי בוחר ענף ולולאה חוזרת על איברים. נתב פקודות אינו סוכן: ההחלטה נמצאת בקוד.

יישם את ההסבר על התוצר שלך: סמן מה נקבע מראש בקוד, מה נקרא ממקור ומה נוצר או הוערך על ידי מודל. אלה מסלולים שונים של אחריות. ערך שנוצר אינו נעשה עובדה רק מפני שהוא כתוב בשדה מובנה.

### תחביר דרך הדוגמה

`command = 'extract'` משייך מחרוזת למשתנה. `['a', 'b']` היא רשימה; `{'action': 'extract'}` הוא מילון. `True` ו־`False` הם ערכים בוליאניים. `if` בוחר מסלול לפי תנאי. `for item in items` עובר על איברי רשימה. Python משתמש בהזחה כדי לקבוע אילו הוראות שייכות לאותו בלוק.

`def route(command, text):` מגדיר פונקציה. הפרמטרים הם שמות לקלט; `return` מחזיר תוצאה למי שקרא לה. `print` מציג למשתמש, ולכן אינו תחליף להחזרת נתונים. רמזי טיפוס כמו `text: str` אינם בודקים את הקלט בזמן הריצה; הבדיקה המפורשת ב־`isinstance` עושה זאת.

בדוגמה, המילון `handlers` מחבר שם פקודה לפונקציה. `lambda` היא פונקציה קצרה המחזירה ביטוי. אפשר להחליף אותה בפונקציה בשם. `strip()` מסיר רווחים בקצוות, `split()` ללא מפריד מפצל לפי תווים לבנים, כגון רווח או ירידת שורה ו־`[:40]` בוחר עד 40 תווים. זוהי הדגמה מקומית: research אינו מבצע חיפוש, summarize אינו מסכם באמצעות מודל.
