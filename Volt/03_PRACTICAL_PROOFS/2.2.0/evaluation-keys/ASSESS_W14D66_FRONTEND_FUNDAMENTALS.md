# תנאי בדיקה: הוכחה מעשית · React ו־Next.js למערכות AI

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: בנה טופס ליצירת ריצה, רשימת ריצות ותצוגת תוצאה. הוסף מצבים של טעינה (loading), אין נתונים (empty) ושגיאה (error). הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: DEPLOYMENT

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: גרום לתשובה ישנה להגיע אחרי תשובה לבקשה חדשה. בדוק איזה מידע מוצג. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: MONITORING

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: מנע הצגת תוצאה שאינה שייכת לבקשה הנוכחית. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: DEPLOYMENT
