# תנאי בדיקה: הוכחה מעשית · עבודה במקביל

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: הרץ שלוש קריאות מחקר שאינן תלויות זו בזו באמצעות asyncio. אסוף את התוצאות שהצליחו ואת השגיאות בנפרד, כדי שכשל של קריאה אחת לא יוסתר. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: WORKFLOWS

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: השהה תהליך אחד (Worker) והכשל אחר. בדוק איך נאספות התוצאות שנותרו. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: DURABLE_EXECUTION

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: הגבל את מספר הפעולות בו־זמנית. השווה זמן ותוצאה לאותה משימה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
