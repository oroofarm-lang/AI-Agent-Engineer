# תנאי בדיקה: הוכחה מעשית · מבחן מסכם: שתי ארכיטקטורות לאותה מערכת

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: בנה את אותה מערכת בשתי דרכים: לולאה ידנית, ו־SDK או גרף (Graph). כתוב מה היתרונות והחסרונות של כל דרך, ואיזו מתאימה לדרישות שלך. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: AGENT_LOOP

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: הרץ בשתי הגרסאות אותו כשל כלי ואותה הפעלה מחדש (Restart). השווה את התנהגותן. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: TRACING

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: שנה את הדרישה לשמירת מצב ונמק אם הבחירה בין הארכיטקטורות עדיין מתאימה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
