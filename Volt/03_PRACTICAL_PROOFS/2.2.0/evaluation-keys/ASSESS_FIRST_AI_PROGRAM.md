# תנאי בדיקה: מתיקייה ריקה לתוכנית עובדת

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. CRITERION_REBUILD

- [ ] העבודה מתייחסת לדרישה: שחזר סביבה וירטואלית ותוכנית שמקבלת שאלה ומדפיסה תשובה. הסבר מה כל חלק בקוד עושה.
- [ ] צורפו ראיות שאפשר לבדוק: צרף את הפקודות, קוד התוכנית ופלט מהרצה שלך. ציין את גרסת Python והחבילה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: PYTHON

## 2. CRITERION_REQUEST_PATH

- [ ] העבודה מתייחסת לדרישה: תאר את מסלול הבקשה מהמחשב לשירות ובחזרה. הבחן בין Python, ה־SDK, ה־API והמודל.
- [ ] צורפו ראיות שאפשר לבדוק: השתמש בדוגמה מההרצה שלך. מה מקומי, מה מרוחק, ואיפה מתבצע האימות?
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: HTTP_APIS

## 3. CRITERION_DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: הצג כשל מקומי וכשל שירות, והסבר כיצד איתרת את הסיבה והוכחת שהתיקון עבד.
- [ ] צורפו ראיות שאפשר לבדוק: צרף הודעות שגיאה ללא סודות, השערה, בדיקת אבחון ותוצאת הרצה לאחר תיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: PYTHON

## 4. CRITERION_GIT_SECRETS

- [ ] העבודה מתייחסת לדרישה: הראה אילו קבצים נכללים במאגר ואילו הוחרגו. הסבר כיצד וידאת שמפתח ה־API לא נשמר בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף את .gitignore ופלט git status או git ls-files. אל תצרף את המפתח עצמו.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: GIT
