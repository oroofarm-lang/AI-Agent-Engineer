# תנאי בדיקה: הוכחה מעשית · תכנון נתוני הערכה

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: כתוב לפחות 30 מקרי בדיקה. לכל אחד תן מזהה, קלט, תוצאה צפויה וקטגוריה. שמור חלק מהמקרים למדידה הסופית ואל תשתמש בהם בזמן שיפור המערכת. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: EVALS

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: כלול דוגמאות כמעט זהות בנתוני הפיתוח ובנתוני הבדיקה. מצא את החפיפה. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: TESTING

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: תקן את החלוקה והסבר אילו מצבים עדיין אינם נכללים בנתונים. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.
