# תנאי בדיקה: הוכחה מעשית · פירוק משימות מחקר

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: תכנן מחקר להשוואת שלושה ספקי שירות לעסק. כתוב לפי מה תשווה ביניהם, אילו שאלות צריך לברר ואילו מקורות יידרשו. שמור את התוכנית במבנה נתונים שאפשר לעדכן. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: PLANNING

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: הוסף לתוכנית שאלות שאינן משפיעות על בחירת הספק. מצא אותן והסבר מדוע הן מיותרות. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: GROUNDING

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: שנה מגבלה עסקית אחת ועדכן רק את החלקים בתוכנית שהושפעו ממנה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: PLANNING
