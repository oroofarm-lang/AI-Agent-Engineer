# תנאי בדיקה: הוכחה מעשית · Prompting, ‏RAG ו־Fine-tuning

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: בחר גישה לשלושה צרכים עסקיים והסבר את ההחלטה. בצע ניסוי קטן רק אם יש נתונים ומשאבים מתאימים, והשווה את התוצאה לבדיקה נפרדת. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: AI_FUNDAMENTALS

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: בדוק שיפור על נתוני האימון שאינו מופיע בנתוני הבדיקה. הסבר מה עדיין לא נלמד. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: EVALS
