# תנאי בדיקה: הוכחה מעשית · מבחן מסכם: סוכן מחקר

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: עבוד לפי המפרט בלבד: קבל יעד מחקר, תכנן את הבדיקה, חפש, תעד ראיות וסתירות והפק דוח עם מקורות. השתמש ברכיבים שבנית בשיעורים הקודמים, בלי פתרון מוכן. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: PLANNING

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: הדגם שירות חיפוש שאינו זמין ומקור שסותר את התשובה הראשונית. בדוק איך הסוכן מסיים ומציג את המגבלה. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: GROUNDING

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: בצע מחקר חדש בלי הוראות צעד אחר צעד. נמק את המסקנה בעזרת המקורות שאספת. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: PLANNING
