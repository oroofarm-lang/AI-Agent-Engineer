# תנאי בדיקה: הוכחה מעשית · מצב משותף ותיאום

אלה תנאי בדיקה המבוססים על המחוון שפורסם. הם אינם מפתח תשובות מלא, ציונים מחושבים או תוצאות הרצה. במשימות שיש להן כמה פתרונות יש לבחון את הנימוק והראיות ביחס לתנאים.

## 1. BUILD

- [ ] העבודה מתייחסת לדרישה: קבע מי רשאי לעדכן כל שדה, ושמור גרסה של המצב. הוסף בדיקה לעדכונים סותרים ורכיב ביקורת (Reviewer) להצעת העבודה. הראה תוצר והסבר כיצד בדקת אותו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: MANAGER

## 2. DIAGNOSE

- [ ] העבודה מתייחסת לדרישה: תן לשני מומחים לעדכן אותו שדה בערכים שונים. בדוק כיצד הסתירה מזוהה. תעד את האבחון ואת התיקון שבדקת.
- [ ] צורפו ראיות שאפשר לבדוק: כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: COORDINATION

## 3. TRANSFER

- [ ] העבודה מתייחסת לדרישה: קבע כלל לפתרון הסתירה ושמור את הראיות שכל מומחה השתמש בהן. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.
- [ ] צורפו ראיות שאפשר לבדוק: צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
- [ ] הוסבר כיצד הראיות תומכות בטענה ומה עדיין לא נבדק.

מיומנות קשורה: MANAGER
