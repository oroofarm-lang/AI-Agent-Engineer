# הוכחה מעשית · לולאת סוכן ידנית

## תנאי ההגשה

### 1. BUILD

ממש את הסדר GOAL → MODEL → VALIDATE → TOOL → OBSERVATION → MODEL בלי מסגרת פיתוח (Framework). שמור מזהה לכל קריאה, והגדר כמה צעדים מותר לבצע לפני עצירה. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

הזן רצף החלטות קבוע שבו אותו כלי מתבקש שוב בלי התקדמות. בדוק מתי הלולאה נעצרת. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

הוסף עצירה עם המצב budget_exhausted ותעד איזו מגבלה הופעלה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
