# הוכחה מעשית · SDK לסוכנים

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

בנה סוכן (Agent) בעזרת ה־SDK, עם שני כלים, שמירת שיחה (Session) ותיעוד ריצות (Tracing). בדוק אותו על אותם תרחישים שבהם בדקת את הסוכן הידני. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

בדוק כלי שמחזיר שגיאה והעברת טיפול (Handoff) שלא ציפית לה. אתר אותן בתיעוד. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

השווה את תיעוד הריצה (Trace) ב־SDK לאירועים שתיעדת בסוכן הידני. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
