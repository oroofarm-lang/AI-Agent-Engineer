# הוכחה מעשית · פרויקט גמר: בנייה

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

בנה את המסלול המרכזי בעזרת רכיבים משיעורים קודמים. הוסף נתוני בדיקה ובדיקות שמוודאות שהרכיבים מעבירים ביניהם נתונים במבנה שהוגדר. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

גרום לשלב חיצוני להחזיר נתונים במבנה שונה מהצפוי. בדוק היכן נעצרים. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

הדגם מסלול תקין ומסלול שנכשל, עם מצב שנשמר ומאפשר להבין מה קרה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
