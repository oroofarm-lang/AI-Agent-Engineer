# מתיקייה ריקה לתוכנית עובדת

סגור את דוגמת הקוד ושחזר את הפרויקט מתיקייה חדשה בעזרת תיעוד בלבד. צרף קוד, פלט והסבר לכל סעיף. אל תכלול מפתחות API או מידע פרטי. ההגשה נשמרת כתיק ראיות ואינה מריצה קוד או מעניקה ציון; מנגנון הבדיקה העצמאית עדיין בפיתוח.

## תנאי ההגשה

### 1. CRITERION_REBUILD

שחזר סביבה וירטואלית ותוכנית שמקבלת שאלה ומדפיסה תשובה. הסבר מה כל חלק בקוד עושה.

**מה לצרף:** צרף את הפקודות, קוד התוכנית ופלט מהרצה שלך. ציין את גרסת Python והחבילה.

### 2. CRITERION_REQUEST_PATH

תאר את מסלול הבקשה מהמחשב לשירות ובחזרה. הבחן בין Python, ה־SDK, ה־API והמודל.

**מה לצרף:** השתמש בדוגמה מההרצה שלך. מה מקומי, מה מרוחק, ואיפה מתבצע האימות?

### 3. CRITERION_DIAGNOSE

הצג כשל מקומי וכשל שירות, והסבר כיצד איתרת את הסיבה והוכחת שהתיקון עבד.

**מה לצרף:** צרף הודעות שגיאה ללא סודות, השערה, בדיקת אבחון ותוצאת הרצה לאחר תיקון.

### 4. CRITERION_GIT_SECRETS

הראה אילו קבצים נכללים במאגר ואילו הוחרגו. הסבר כיצד וידאת שמפתח ה־API לא נשמר בו.

**מה לצרף:** צרף את .gitignore ופלט git status או git ls-files. אל תצרף את המפתח עצמו.
