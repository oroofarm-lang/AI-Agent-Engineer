# הוכחה מעשית · פירוק משימות מחקר

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

תכנן מחקר להשוואת שלושה ספקי שירות לעסק. כתוב לפי מה תשווה ביניהם, אילו שאלות צריך לברר ואילו מקורות יידרשו. שמור את התוכנית במבנה נתונים שאפשר לעדכן. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

הוסף לתוכנית שאלות שאינן משפיעות על בחירת הספק. מצא אותן והסבר מדוע הן מיותרות. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

שנה מגבלה עסקית אחת ועדכן רק את החלקים בתוכנית שהושפעו ממנה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
