# הוכחה מעשית · מבחן מסכם: אתר המחובר למערכת AI

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

הגש אתר עסקי עם טופס, שרת (Backend) ותהליך עבודה מחובר. הוסף מדריך שמסביר כיצד לערוך את תוכן האתר ולבדוק שהפניות מגיעות ליעדן. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

נתק את שירות ה־AI בזמן שליחת פנייה. בדוק אם הפנייה נשמרה. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

שמור את הפנייה והצג דרך חלופית להמשך הטיפול. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
