# הוכחה מעשית · פרויקט: סוכן זיכרון אישי

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

ממש את פעולות הזיכרון remember, retrieve, update, ignore ו־delete. בכל פעולה בדוק את מזהה המשתמש ותעד ביומן מה התבקש ומה בוצע. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

נסה ממשתמש ב׳ לקרוא זיכרון של משתמש א׳. בדוק שהבקשה נדחית. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

הוסף תאריך תפוגה ובדיקה שמזהה מידע בזיכרון שכבר אינו תקף. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
