# הוכחה מעשית · ממשק לסוכן ולפעולותיו

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

בנה תצוגה של הריצה, פעולות הכלים, הטיוטה והאישור. אפשר ביטול והצג במפורש כשהתוצאה חלקית. לפני אישור הראה מה עומד להשתנות. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

הצג כפתור אישור בלי פרטי הפעולה. בדוק אם משתמש אחר מבין מה הוא מאשר. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

תקן את התצוגה ובקש ממשתמש אחר להסביר איזו פעולה תתבצע לאחר האישור. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
