# הוכחה מעשית · בחירת מודלים לפי מדידה

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

השווה מודלים על סיווג, חילוץ וסיכום. שמור בטבלה את מזהי המודלים, הגרסאות, הקלטים והתוצאות. השתמש רק בשירותים שיש לך גישה אליהם ותעד את המגבלות. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

בדוק מקרה שבו מודל יקר יותר אינו משפר את חילוץ הפרטים. השווה עלות ותוצאה. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

בחר מודל לשלב אחד וכתוב אילו תוצאות בדיקה יגרמו לך לשנות את הבחירה. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
