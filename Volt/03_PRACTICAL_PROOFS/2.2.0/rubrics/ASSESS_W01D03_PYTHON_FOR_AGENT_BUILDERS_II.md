# הוכחה מעשית · Python לבוני סוכנים · חלק ב׳

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

כתוב פונקציות save_messages ו־load_messages לשמירה ולטעינה של שיחה. בכל הודעה שמור role ו־content. כתוב בקידוד UTF-8 ובדוק את סוגי הערכים. החזר שיחה ריקה רק אם הקובץ אינו קיים. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

נסה לטעון קובץ פגום, ואז JSON שמכיל אובייקט במקום רשימה. בדוק שהקובץ המקורי נשמר גם כשהטעינה נכשלת. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

תן לכל שיחה מזהה והוסף אפשרות לבחור איזו שיחה לטעון. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
