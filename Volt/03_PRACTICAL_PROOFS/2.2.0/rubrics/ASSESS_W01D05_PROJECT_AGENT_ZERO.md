# הוכחה מעשית · פרויקט: Agent Zero

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

כתוב כלי שקורא את קטלוג המעבדה, וחבר מודל שבוחר אם להשתמש בו. החזר תשובה במבנה שהגדרת ותעד כל צעד. אם אתה בודק בעזרת תשובות קבועות במקום מודל, סמן בבירור שזו בדיקת תוכנה. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

גרום לכלי להחזיר שגיאה. בדוק שהסוכן מציין שחסר מידע ואינו ממציא נתוני מלאי. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

חבר קטלוג אחר בלי לשנות את הקוד שמנהל את לולאת הסוכן. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
