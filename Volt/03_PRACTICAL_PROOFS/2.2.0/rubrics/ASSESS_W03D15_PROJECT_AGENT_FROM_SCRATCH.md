# הוכחה מעשית · פרויקט: סוכן מאפס

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

בנה סוכן עם שלושה כלים, מגבלות פעולה ותוצאה סופית במבנה מוגדר. אל תשתמש במסגרת סוכנים. בדוק את הקוד גם בעזרת תשובות מודל קבועות, כדי ליצור כשלים בצורה מבוקרת. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

הכשל כלי אחד אחרי שכלי אחר הצליח. בדוק שהתוצאה מציינת מה הושלם ומה נכשל. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

קבל תיעוד של כלי שלא הכרת. הוסף אותו לסוכן בעזרת התיעוד בלבד. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
