# הוכחה מעשית · מסמכים, תמונות וקול כקלט

צרף תוצר וראיות שאפשר לבדוק. בכל סעיף כתוב הסבר וצרף דוגמה ותוצאה. ההגשה שומרת את העבודה לצורך בדיקה. היא אינה מריצה את הקוד ואינה מחשבת ציון באופן אוטומטי.

## תנאי ההגשה

### 1. BUILD

הכן אותה פנייה בשלוש צורות: טקסט, PDF והקלטה. חלץ את הפרטים לאותו מבנה וצרף לכל פרט את המקור שלו. השתמש בקבצים שהומצאו לתרגול. הראה תוצר והסבר כיצד בדקת אותו.

**מה לצרף:** צרף קלט, פלט, גרסה ופקודת הרצה או מסמך אפיון עם מבחן קבלה.

### 2. DIAGNOSE

השתמש בסריקה מטושטשת ובהקלטה שבה שם תומלל לא נכון. מצא את הפערים מול המקור. תעד את האבחון ואת התיקון שבדקת.

**מה לצרף:** כתוב מה ציפית לקבל. צרף את התוצאה לפני התיקון, את הבדיקה שעזרה למצוא את התקלה ואת התוצאה לאחר התיקון.

### 3. TRANSFER

סמן אילו פרטים דורשים בדיקה אנושית והסבר מה לא נקרא בביטחון. הצג פתרון עצמאי וציין מקרה שהפתרון אינו מטפל בו.

**מה לצרף:** צרף תוצר חדש, החלטה מנומקת ומקרה שבו הפתרון אינו מספיק.
