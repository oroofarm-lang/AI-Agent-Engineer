# כיוון כתיבה עברי בקובץ PDF

[קובץ המקור הציבורי](https://github.com/oroofarm-lang/AI-Agent-Engineer/blob/main/src/lib/templates/pdf-text.tsx)

סוג הקובץ: `template-code`. נתיב במאגר הציבורי: `src/lib/templates/pdf-text.tsx`.

זהו קובץ קוד ציבורי. הכללתו בכספת אינה מעידה שבוצעה כאן הרצה.

## תוכן הקובץ הציבורי

```
import type { PropsWithChildren } from 'react';
import { Text as PDFText, type TextProps } from '@react-pdf/renderer';

/** Renderer direction is not inherited. Set it on each text node, preserving explicit LTR code. */
export function TemplateText({ style, ...props }: PropsWithChildren<TextProps>) {
  const styles = Array.isArray(style) ? style : [style ?? {}];
  return <PDFText {...props} style={[{ direction: 'rtl' }, ...styles]} />;
}

```
