**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

הטופס נשלח, הרשת נותקה, והמשתמש מנסה שוב. מה עוזר למנוע יצירת שתי פניות?

- A: מזהה פעולה שמאפשר לזהות שהשליחה חוזרת
- B: בדיקת קלט בדפדפן בלבד
- C: החלפת נוסח כפתור השליחה בלי לבדוק מה נשמר

## תשובה והסבר ללמידה

אפשרות: A.

המשתמש עשוי לא לדעת אם השרת קיבל את הפנייה לפני הניתוק. השיעור מציע מזהה פעולה לזיהוי שליחה חוזרת, לצד בדיקת קלט בדפדפן ובשרת, כדי למנוע פנייה כפולה.
