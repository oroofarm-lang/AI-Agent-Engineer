# בדיקת הבנה: שני מומחים מציעים ערכים שונים לאותו שדה במצב המשותף. מה נדרש?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

שני מומחים מציעים ערכים שונים לאותו שדה במצב המשותף. מה נדרש?

- A: כלל הרשאה ופתרון סתירה, לצד שמירת גרסת המצב והראיות
- B: לבחור תמיד את ההצעה שהגיעה אחרונה בלי לבדוק
- C: לתת לכל מומחה לשנות כל שדה כדי למנוע המתנה

## תשובה והסבר ללמידה

אפשרות: A.

עדכונים משותפים מחייבים לקבוע מי רשאי לשנות כל שדה ואיך מזהים ופותרים סתירות. רכיב הביקורת בודק לפי תנאים מוגדרים ולא רק מסכים עם ההצעה.

קטע מקור בשיעור: Build First. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
