# בדיקת הבנה: איזה ניסוי בודק התאוששות לאחר הפעלה מחדש של תהליך העבודה?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

איזה ניסוי בודק התאוששות לאחר הפעלה מחדש של תהליך העבודה?

- A: לתפוס חריגה בלי להפסיק את התהליך
- B: להציג טקסט ״המערכת התאוששה״ בלי לטעון מצב שמור
- C: לסגור את התוכנית בפועל, להפעילה מחדש ולבדוק מאיזה מצב היא ממשיכה

## תשובה והסבר ללמידה

אפשרות: C.

השיעור מבחין בין טיפול בחריגה לבין סגירה והפעלה מחדש. כדי לבדוק התאוששות צריך לטעון את המצב השמור ולבחון את המשך העבודה.
