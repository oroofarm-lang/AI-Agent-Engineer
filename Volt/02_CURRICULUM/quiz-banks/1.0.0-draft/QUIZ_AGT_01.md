# בדיקת הבנה: מה מתאר Agent Card בתרגיל התקשורת בין שירותים?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

מה מתאר Agent Card בתרגיל התקשורת בין שירותים?

- A: את יכולות שירות הבדיקה, לפי גרסת המפרט שנבחרה
- B: הרשאה אוטומטית לבצע כל משימה מכל משתמש
- C: את תוצאות כל המחקרים העתידיים של השירות

## תשובה והסבר ללמידה

אפשרות: A.

התרגיל דורש לקרוא את כרטיס הסוכן ולבדוק אילו יכולות השירות מצהיר עליהן. תקן תקשורת וכרטיס יכולות אינם מחליפים בדיקת הרשאות או אחריות לתוצאה.

קטע מקור בשיעור: Build First. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
