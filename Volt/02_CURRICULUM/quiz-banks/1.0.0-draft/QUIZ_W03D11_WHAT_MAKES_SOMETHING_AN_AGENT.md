# בדיקת הבנה: באיזה מקרה המודל פועל כסוכן, לפי ההבחנות בקורס?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

באיזה מקרה המודל פועל כסוכן, לפי ההבחנות בקורס?

- A: הקוד מבצע תמיד אותם שלושה שלבים קבועים
- B: המודל בוחר במהלך הריצה פעולה או צעד המשך בתוך גבולות המערכת
- C: התוכנית מציגה תשובת מודל אחת בלי בחירת צעדים

## תשובה והסבר ללמידה

אפשרות: B.

בתהליך קבוע הקוד קובע את סדר השלבים. בסוכן המודל בוחר חלק מהצעדים בזמן הריצה, והקוד עדיין בודק הרשאות וגבולות.
