מדוע שומרים חלק ממקרי הבדיקה למדידה הסופית?

- A: כדי לא למדוד רק דוגמאות שכבר התאימו אליהן את המערכת
- B: כדי לאפשר שינוי התוצאה הצפויה לאחר כל הרצה
