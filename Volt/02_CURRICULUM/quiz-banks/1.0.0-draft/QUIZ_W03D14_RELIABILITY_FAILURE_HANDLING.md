# בדיקת הבנה: פעולת כתיבה הסתיימה בהמתנה ארוכה, ולא ברור אם כבר שינתה נתונים. מה נכון לעשות לפני ניסיון חוזר?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

פעולת כתיבה הסתיימה בהמתנה ארוכה, ולא ברור אם כבר שינתה נתונים. מה נכון לעשות לפני ניסיון חוזר?

- A: לנסות מיד שוב ללא מגבלה
- B: לברר מה בוצע לפני שליחת הכתיבה שוב
- C: לשנות את נוסח ההנחיה ולסמן את הכתיבה כהצלחה

## תשובה והסבר ללמידה

אפשרות: B.

התרגיל מבדיל בין ניסיון חוזר של קריאה לבין כתיבה שמצבה אינו ידוע. ניסיון חוזר עלול לבצע את השינוי שוב, ולכן קודם בודקים מה כבר קרה.

קטע מקור בשיעור: Build First. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
