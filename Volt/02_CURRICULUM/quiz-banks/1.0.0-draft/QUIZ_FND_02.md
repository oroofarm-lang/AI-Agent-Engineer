# בדיקת הבנה: מהי השוואה מתאימה לבחירת מודל למשימת חילוץ?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

מהי השוואה מתאימה לבחירת מודל למשימת חילוץ?

- A: אותה משימה ואותם נתונים, עם מדידת איכות, זמן, עלות ומגבלות
- B: משימות שונות לכל מודל, לפי הדוגמה שבה הוא מצליח
- C: בחירה אוטומטית במודל היקר ביותר
