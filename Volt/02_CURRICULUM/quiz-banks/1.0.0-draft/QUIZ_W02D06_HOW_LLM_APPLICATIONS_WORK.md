# בדיקת הבנה: מה ההבדל בין טוקן לבין מילה שלמה?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

מה ההבדל בין טוקן לבין מילה שלמה?

- A: כל טוקן הוא תמיד משפט שלם
- B: מספר הטוקנים זהה למספר התווים בכל שפה
- C: טוקן הוא יחידת ייצוג שהמודל מעבד, ואינו בהכרח מילה שלמה

## תשובה והסבר ללמידה

אפשרות: C.

השיעור מגדיר טוקנים כיחידות ייצוג. חלוקת אותו משפט לטוקנים עשויה להשתנות בין שפות, ולכן אין להחליף מדידת שימוש בספירת מילים או תווים.
