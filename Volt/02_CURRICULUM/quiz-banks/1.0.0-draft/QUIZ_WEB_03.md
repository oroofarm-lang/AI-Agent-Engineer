# בדיקת הבנה: כרטיס בדף שנוצר בעזרת AI נראה טוב במחשב אך חורג מרוחב הטלפון. מה נדרש כדי להשלים את הבנייה?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

כרטיס בדף שנוצר בעזרת AI נראה טוב במחשב אך חורג מרוחב הטלפון. מה נדרש כדי להשלים את הבנייה?

- A: להסתפק בצילום מהמחשב שבו נבנה הדף
- B: לבקש עוד גרסה מהמודל בלי לקרוא את הקוד או לבדוק אותה
- C: לזהות את גורם החריגה, לתקן ולבדוק בכמה גדלי מסך

## תשובה והסבר ללמידה

אפשרות: C.

קוד שנוצר בעזרת AI מחייב קריאה ובדיקה. ממשק מותאם צריך לעבוד גם במסך קטן, והתרגיל דורש לזהות חריגה ולבדוק את התיקון בטלפון, בטאבלט ובמחשב.

קטע מקור בשיעור: Mastery Check. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
