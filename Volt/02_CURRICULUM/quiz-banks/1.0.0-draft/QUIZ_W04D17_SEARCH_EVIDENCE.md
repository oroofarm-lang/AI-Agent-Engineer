# בדיקת הבנה: איזה מידע כדאי לשמור לצד טענה שנמצאה במחקר?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

איזה מידע כדאי לשמור לצד טענה שנמצאה במחקר?

- A: רק הכותרת של תוצאת החיפוש
- B: כתובת המקור, תאריך וקטע שמבסס את הטענה
- C: רק מספר האתרים שבהם הופיע אותו ניסוח

## תשובה והסבר ללמידה

אפשרות: B.

התרגיל דורש URL, תאריך, קטע תומך וסוג מקור. הנתונים מאפשרים לבדוק אם המקור אכן תומך בטענה ולא רק מזכיר את הנושא.
