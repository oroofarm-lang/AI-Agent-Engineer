# בדיקת הבנה: בשלוש קריאות מחקר בו־זמניות, קריאה אחת נכשלת. מה צריך שלב איסוף התוצאות לעשות?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

בשלוש קריאות מחקר בו־זמניות, קריאה אחת נכשלת. מה צריך שלב איסוף התוצאות לעשות?

- A: להציג את התוצאות שהצליחו ואת הכשל בנפרד
- B: לסמן את כל שלוש הקריאות כהצלחה
- C: להסתיר את הכשל כדי שהדוח ייראה שלם

## תשובה והסבר ללמידה

אפשרות: A.

התרגיל דורש איסוף נפרד של הצלחות ושגיאות. Fan-in מחבר תוצאות, אך צריך מדיניות ברורה לתשובה חסרה או שגיאה.

קטע מקור בשיעור: Build First. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
