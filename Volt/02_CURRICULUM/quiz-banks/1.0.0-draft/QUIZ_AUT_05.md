# בדיקת הבנה: טיוטת תשובה שונתה אחרי אישור בתהליך החזותי. מה נדרש כדי להמשיך?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

טיוטת תשובה שונתה אחרי אישור בתהליך החזותי. מה נדרש כדי להמשיך?

- A: להשאיר את האישור הקודם מפני שהכרטיס נשאר ירוק
- B: למחוק את מספר הגרסה כדי שההשוואה תצליח
- C: לבטל את האישור הישן ולאשר את הגרסה החדשה

## תשובה והסבר ללמידה

אפשרות: C.

האדם אישר פעולה וגרסה מסוימות. האתגר דורש לבטל אישור ישן ולאפשר המשך רק לאחר אישור לגרסה החדשה.

קטע מקור בשיעור: Challenge. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
