מה צריך לקרות לאחר שהקוד מפעיל כלי בלולאת הסוכן?

- B: לשלוח למודל רק את המטרה המקורית ולמחוק את התוצאה
- C: לסמן את כל המשימה כהצלחה בלי לבדוק אם הושלמה
