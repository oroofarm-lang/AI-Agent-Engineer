# בדיקת הבנה: איך בודקים שה־Sandbox אוכף את הגבולות שהוגדרו?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

איך בודקים שה־Sandbox אוכף את הגבולות שהוגדרו?

- A: מסתפקים בשם ״Sandbox״ בלי ניסוי
- B: מריצים את הקוד על מידע אמיתי של לקוח כדי להגדיל אמינות
- C: מנסים בסביבת בדיקה קריאה מחוץ לתיקייה והרצה שאינה עוצרת, ובודקים חסימה

## תשובה והסבר ללמידה

אפשרות: C.

המעבדה דורשת לבדוק גישה מחוץ לסביבה והרצה ללא עצירה. Sandbox הוא חלק מההגנות, ולא הבטחת בטיחות מעצם שמו.
