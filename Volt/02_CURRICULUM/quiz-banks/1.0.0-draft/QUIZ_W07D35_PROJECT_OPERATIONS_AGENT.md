**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

הסוכן הכין טיוטת עדכון CRM אך טרם קיבל אישור. מה מותר להציג?

- A: שהעדכון בוצע במערכת ה־CRM
- B: שהעדכון מוכן כטיוטה וממתין לאישור
- C: שהאישור נחשב מיותר מפני שהטיוטה תקינה

## תשובה והסבר ללמידה

אפשרות: B.

הפרויקט מפריד בין הכנת פעולה, אישורה וביצועה. אין להציג עדכון כמבוצע כאשר המערכת רק הכינה אותו.
