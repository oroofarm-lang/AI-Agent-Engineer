# בדיקת הבנה: מה בודקת הדמיה שמחזירה רצף החלטות קבוע במקום מודל אמיתי?

**טיוטה לביקורת אנושית — אינה פעילה בשיעורים.**

מה בודקת הדמיה שמחזירה רצף החלטות קבוע במקום מודל אמיתי?

- A: את איכות התשובות של המודל האמיתי
- B: את זמינות השירות המרוחק בחשבון של הלקוח
- C: את תגובת תוכנת הסוכן להחלטות ולכשלים מבוקרים

## תשובה והסבר ללמידה

אפשרות: C.

הפרדת החיבור למודל מהכלים ומהבקר מאפשרת לבדוק את התוכנה בלי קריאות בתשלום. השיעור מציין שבדיקה זו אינה מודדת את איכות המודל האמיתי.

קטע מקור בשיעור: Concepts. השאלה מיועדת לחיזוק הבנה; היא אינה אישור שליטה מקצועית.
