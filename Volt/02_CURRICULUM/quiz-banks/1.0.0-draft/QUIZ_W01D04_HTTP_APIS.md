שרת המעבדה החזיר קוד 200, אבל גוף התגובה הוא not-json. היכן עלולה הקריאה להיכשל?

- A: בפענוח גוף התגובה כ־JSON
- B: בבדיקת קוד 404 שהשרת החזיר
- C: רק בשלב אימון המודל על התגובה

## תשובה והסבר ללמידה

אפשרות: A.
