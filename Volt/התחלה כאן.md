## איך עובדים?

פתח שיעור מהתוכנית וכתוב את הסיכום שלך במחברת. חומר הקורס כאן הוא עותק לקריאה של גרסה 2.1.0. השמירה ב־Obsidian אינה משנה ציונים או התקדמות באפליקציה. הפקודה `npm run vault:sync` מעדכנת את חומר הלימוד מהגרסה הפעילה ושומרת גרסאות קודמות. היא אינה דורסת קובץ ששינית בעצמך.

כדי לפתוח את התיקייה: ב־Obsidian בחר **Open folder as vault**, ואז בחר את התיקייה `Volt` שבפרויקט. [הוראות רשמיות](https://obsidian.md/help/manage-vaults).
