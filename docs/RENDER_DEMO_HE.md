# תצוגת ניסיון חינמית ב־Render

החלטה: תצוגת ניסיון בלבד, בלי שינוי מסד הנתונים ל־PostgreSQL ובלי להעביר נתונים מהמחשב. חשבונות, העלאות והתקדמות בענן זמניים ועלולים להימחק בהפעלה מחדש, בכיבוי עקב חוסר פעילות או בפריסה חדשה. הגיבוי המקומי אינו גיבוי של חשבונות הענן.

בחר Docker, הענף main, Frankfurt ומסלול Free ($0). אל תוסיף דיסק, שירות מסד בתשלום או מפתח מודל בתשלום לצורך תצוגה זו. כל חשבון עדיין נדרש להתחבר ולאמת מייל; אין לעקוף את האימות.

הגדר במנהל הסודות ב־Render בלבד:

- `PORT=10000`
- `DEMO_MODE=true`
- `BETTER_AUTH_SECRET`: ערך אקראי ייחודי לשרת, לפחות 32 תווים.
- `MAIL_PROVIDER=gmail`, `MAIL_FROM`, `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN`: החיבור המאומת. העבר רק אחרי אישור העברת הסודות ל־Render, בלי צ׳אט, Git או צילומי מסך.
- `LEGAL_OPERATOR`, `LEGAL_CONTACT_EMAIL`, `ADMIN_EMAILS`: המפעיל ופרטי הקשר הנכונים.

בהפעלה ב־Render בלבד, אם `BETTER_AUTH_URL` לא הוגדר, נקודת הכניסה משתמשת ב־`RENDER_EXTERNAL_URL` הרשמי. אין צורך לנחש את הכתובת. בתחילת השירות נוצר מסד חדש מתוך המיגרציות; לא נשלח מסד המשתמשים המקומי.

התצוגה החינמית עדיין מקבלת כתובת הנגישה באינטרנט. `noindex` והכיתוב ״גרסת ניסיון״ אינם הגנת גישה או פרטיות. אין להפיץ אותה לקהל או להשתמש במידע אמיתי. SMTP חסום במסלול החינמי; Gmail API משתמש ב־HTTPS. הרשאת Gmail במצב Testing זמנית ואינה הכנה להפעלה רציפה.

אחרי הפריסה: בדוק תגובת /auth, הרשמה לחשבון בדיקה בבעלותך, הגעת מייל האימות, כניסה ושמירת צעד. אל תסיק שמירה ארוכת טווח מבדיקה אחת. אין להכריז על מנטור AI פעיל בלי בדיקה מול ספק אמיתי; האחסון החינמי אינו כולל שימוש במודל בתשלום.

לפני פתיחה אמיתית: אחסון קבוע וגיבויים עקביים למסד וליומני התוכן, טיפול במחיקות מגיבויים, הגדרת כותרת IP אמינה מהפרוקסי, בדיקות הגבלת בקשות, מייל קבוע ומדיניות מותאמת. ראה DEPLOYMENT.md.

מקורות: [מגבלות Free](https://render.com/docs/free), [משתני הסביבה של Render](https://render.com/docs/environment-variables), [שירותי Web](https://render.com/docs/web-services).
