# Gmail OAuth — 2026-10-04

## שינוי

נוסף ספק Gmail API חלופי ל־SMTP עבור מיילי אימות ואיפוס סיסמה. הקוד משתמש ברענון טוקן וב־messages.send בלבד, בונה MIME מקומית, מגביל זמן בקשה ואינו מנסה לשלוח שוב אוטומטית כאשר תוצאת השליחה אינה ודאית. נוסף כלי הגדרה בטרמינל עם קלט סודות מוסתר ושמירה אטומית ב־.env.local בהרשאות 0600. SMTP נשאר נתמך. המדריך מפנה להגדרת לקוח OAuth משלך והרשאת gmail.send בלבד, ומציין תפוגה של שבעה ימים במצב Testing.

## אימות שבוצע

- npm run lint — עבר.
- npm run typecheck — עבר לאחר הוספת בדיקת Buffer מפורשת לתוצאת MIME.
- vitest: gmail-api, gmail-config, auth — 3 קבצים, 7 בדיקות עברו. תגובות Google ופרטי ההתחברות סינתטיים.
- בדיקות TTY לשני כלי ההגדרה — עברו בתיקיות זמניות עם פרטים סינתטיים: אין הדהוד סודות, הרשאות 0600 והגדרות אחרות נשמרות. לא בוצעו בקשות רשת.
- npm run build — עבר; בדיקות מבנה של 139 שיעורים ו־418 סביבות עבודה עברו. בדיקת פרטיות עברה עבור 40 עקבות בנייה. בדיקות מבנה אינן אישור איכות הוראה.

## לא אומת

לא הוגדרו פרטי OAuth אמיתיים, לא אושר חשבון Google, לא נשלח מייל ולא נבדקה הגעה לתיבה. לא הושלמו פרסום או אימות אפליקציה מול Google. סיבת אי־זמינות סיסמאות האפליקציה בחשבון המשתמש אינה ידועה. אין כאן אישור נגישות, ביקורת עברית מלאה או בדיקת כל תהליכי הממשק. שינויי המנטור הקיימים בעץ העבודה הם עבודה נפרדת ואינם נכללים בגיבוי זה.
