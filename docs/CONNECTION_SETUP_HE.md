# חיבור מייל, חשבון מנהל ו־AI Mentor

כתובת המנהל שהמשתמש בחר נשמרה ב־`.env.local`, שאינו נכלל ב־Git. אין עדיין פרטי ספק מייל או מפתח AI. הקוד לחיבורים נבנה; עצם קיומו אינו מוכיח שהשירותים החיצוניים פועלים.

## 1. מייל בלי דומיין — לצורך בדיקה ראשונית

אפשר לבדוק את חיבור SMTP באמצעות חשבון Gmail שלך. זהו פתרון להפעלה ראשונית; לפני שירות ציבורי יש לבחור ספק מתאים לנפח השליחה ולתנאי השימוש שלו. Google ממליצה על התחברות OAuth כשנתמכת; כאן המערכת משתמשת ב־SMTP עם סיסמת אפליקציה. סיסמת החשבון הרגילה אינה נדרשת ואינה צריכה להימסר.

1. הפעל אימות דו־שלבי בחשבון Google.
2. בדוק אם אפשר ליצור [סיסמת אפליקציה](https://support.google.com/mail/answer/185833?hl=iw). האפשרות אינה זמינה לכל חשבון, למשל בחלק מחשבונות הארגון או בהגנה מתקדמת. אם אינה זמינה, נבחר ספק SMTP אחר; אין צורך להחליש את הגנת החשבון.
3. פתח את `.env.local` במחשב שלך. הוסף את ההגדרות הבאות, והחלף את ערכי הדוגמה. אל תשלח את הסיסמה בצ׳אט:

```dotenv
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=your-address@gmail.com
SMTP_PASSWORD=your-app-password
MAIL_FROM=your-address@gmail.com
# השאר SMTP_URL ריק כשמשתמשים בשדות האלה.
```

4. הרץ `npm run mail:check`. הבדיקה בודקת חיבור והזדהות, ואינה שולחת הודעה או מוכיחה הגעה לתיבה.
5. הפעל מחדש את השרת. הרשמה חדשה תדרוש אימות מייל. היכנס ל־`/auth`, הזן את כתובתך ובקש קישור אימות, או צור חשבון חדש. לחץ על הקישור שהגיע לתיבתך, והתחבר.
6. פתח `/admin`. הגישה דורשת גם כתובת ברשימת המנהלים וגם אימות שהמשתמש שולט בכתובת. כתובת מסומנת כמאומתת רק לאחר פתיחת קישור האימות. נרשמים אחרים אינם מקבלים גישה לרשימה.
7. בדוק גם איפוס סיסמה וקישור שפג תוקפו. תעד הגעה לתיבה ולספאם. קישורים ל־127.0.0.1 עובדים רק במחשב שמפעיל את האפליקציה; כדי להזמין משתמשים מרחוק נדרשים אירוח וכתובת HTTPS ציבורית.

הודעות נשלחות רק לפעולות אימות ואיפוס שביקש המשתמש. מידע על הרשמה אינו הסכמה לדיוור שיווקי.

## 2. AI Mentor

1. צור או בחר פרויקט API בחשבון OpenAI שלך. בדוק הרשאות מודל, חיוב ומגבלות הוצאה בחשבון.
2. צור מפתח API ייעודי והכנס אותו **רק** ל־`.env.local` במחשב שלך. בחר מודל שזמין לפרויקט ותומך ב־Responses API:

```dotenv
OPENAI_API_KEY=your-project-api-key
AI_MODEL=your-available-model-id
```

3. הפעל מחדש את השרת. פתח שיעור מפרק הבסיס ולחץ על AI Mentor. שלח שאלה קצרה ללא סודות. זוהי בקשת API אמיתית שעלולה להיות מחויבת בחשבון שלך.
4. בדוק שמתקבלת תשובה, שהשיחה נשמרת לאחר פתיחה מחדש, ושחשבון אחר אינו רואה אותה. בקש רמז לפני פתרון, ובדוק שהתשובה מועילה ונכונה. מגבלת העזרה היא הנחיה למודל; היא אינה הבטחה לציות.

הקוד משתמש בבקשות שרת בלבד, ב־`store: false`, בזמן המתנה מוגבל וללא ניסיון חוזר אוטומטי. `store: false` אינו הבטחה לאפס שמירה אצל הספק; בדוק את מדיניות הנתונים החלה על הפרויקט. ברירת המחדל שולחת את השאלה, תוכן השיעור ומצב ההתקדמות. הערות, יומן, כשלים וקוד מצורפים רק לפי בחירה מפורשת. השיחה נשמרת במסד של מפעיל האפליקציה ונכללת בייצוא ובמחיקת החשבון.

## 3. פתיחה למשתמשים מרחוק

עדיין נדרשים שרת עם אחסון קבוע ל־SQLite, גיבויים, כתובת HTTPS, הגדרות מפעיל ופרטיות, ובדיקת אימות/איפוס אמיתית. ראה `DEPLOYMENT.md`. אין להעלות את מסד הנתונים או קובצי הסודות ל־Git. אין צורך לקנות דומיין לפני שבודקים את החיבורים המקומיים.

מקורות: [Google — סיסמאות אפליקציה](https://support.google.com/mail/answer/185833), [Nodemailer — בדיקת SMTP](https://nodemailer.com/smtp), [OpenAI — Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses), [מדיניות נתונים](https://developers.openai.com/api/docs/guides/your-data).
